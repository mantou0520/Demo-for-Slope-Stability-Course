判别结果

一、为什么需要赤平投影

岩体中的结构面（层面、节理、断层、片理）在空间中是任意倾斜的平面。要在工程图上比较"坡面、结构面、坡顶面"三者的空间关系， 直接看图很不方便。赤平极射投影把三维的点、线、面压到一个圆里：面的倾角变成半径、面的倾向变成方位、面的相交关系变成点与圆弧的关系， 于是"能不能滑出去"这类问题变成"读图"。

三个要素

  • 投影球：以结构面上某点为球心、任意半径的球。结构面过球心，与球面相交出的是一个大圆。
  • 赤平面（赤道平面）：过球心的水平面，也就是最终的画图平面。
  • 极射点（发射点）：球的上（或下）极点。从极射点向球面上的点连线，射线与赤平面的交点即为该点的投影。
Q = N + u·(P − N)，令 Qz = 0 ⟹ u = R / (R − Pz) 投影点坐标：x' = R·x/(R − z)，y' = R·y/(R − z)

把 |P|=R 的单位球面点写成"自竖直向下方向的夹角 θ"（θ = 90° − 伏角），代入即得最常用的投影半径公式：

等角投影（吴氏网）：r = R · tan(θ/2) 等面积投影（施氏网）：r = R · √2 · sin(θ/2)

二、两种半球约定的差别（课堂上必须讲清楚）

约定发射点（极射点）被投影的半球投影半径大圆凸向极点方位
下半球投影球的上极点下半球r = R·tan(θ/2)，θ 自竖直向下量凸向倾向 αα + 180°
上半球投影球的下极点上半球同上（自竖直向上量）凸向α + 180°α

可以看出：两种约定得到的图，半径数值完全相同，只是整体旋转了 180°。所以"同一个面，用哪种约定画"只影响方位朝向，不影响角距关系。 国内部分工程地质教材习惯用上半球投影，国际岩石力学（ISRM）、Hoek & Bray 的边坡图解法以及工程判稳使用的吴氏网多用下半球等角投影。 用工具里的切换键现场演示一遍，学生就明白二者不是两套理论，只是视角相反。

三、三个关键量的公式（可直接板书）

设结构面倾向 α、倾角 β，R 为基圆半径：

几何量投影半径方位说明
走向点（两个）Rα ± 90°落在大圆与基圆的两个交点上，是"大圆弧的两端"
倾斜线（最陡）投影点R·tan(45° − β/2)α大圆弧上离圆心最近的点，弧顶
极点（法线）R·tan(β/2)α + 180°与弧顶恰好相差 90° 角距，最容易画错的地方
读数口诀：弧端方位 = 走向；弧顶方位 = 倾向；弧顶到圆心的径向距离越大 → 倾角越缓（β=0° 时大圆与基圆重合； β=90° 时大圆退化为过圆心的直径）。极点则相反：基点越靠圆心 → 面越陡（β=90° 的直立面，其极点落在基圆上）。

四、边坡判稳的判据（工具第②页会自动判定）

破坏模式几何判据
平面滑动结构面倾向与坡向之差 ≤ 20°；且倾角 > 摩擦角 φ；且倾角 < 坡角（能在坡面出露）
楔形体滑动两组结构面交棱线 M 的倾伏向与坡向之差 ≤ 20°；倾伏角 > φ；倾伏角 < 坡角
倾倒破坏结构面倾向与坡向相反（倾向 ≈ 坡向 + 180° ± 20°，即倾向坡内、走向与坡面近平行）； 结构面陡立（极点落入摩擦圆外圈：极点伏角 = 90° − 倾角 ≤ φ）；且坡角 ≥ 30°
判别区怎么读——摩擦圆就是分界线：把摩擦圆（半径 r/R = tan(45°−φ/2)）画出来， 圆内靠坡向一侧是滑动出露区，判读对象是大圆弧顶（弧顶落入即 φ < 倾角 < 坡角，能在坡面剪出）； 圆外靠基圆一侧是倾倒区，判读对象是极点（极点落入即结构面陡立且倾向坡内）。 两个区看着像"月牙 + 扇形"，合起来正好铺满坡向 ±20° 的整条径向带。注意判读对象不同：一个是弧、一个是点， 这是初学者最容易混淆的地方。
倾倒判据最容易讲错的一点：倾倒要求结构面"倾向坡内"（倾向与坡向相反），走向与坡面走向近乎平行——坡体像一叠斜插在山里的书， 被坡面切脚后向外倾覆。所以它的方位条件与平面滑动正好相反（平面滑动要求倾向与坡向一致）。 伏角条件各文献取值略有差别：《路基工程》类程序与香港《岩土工程手册》标准图取极点伏角 ≤ φ（摩擦圆为界）； 部分教材取简化的极点伏角 ≤ 30°；Goodman & Bray 原式为 90° − 结构面倾角 ≤ 坡角 − φ。工具把三者都列出来校核。
还要提醒学生："极点方位"的数值随半球约定而变。下半球约定下极点方位 = 倾向 + 180°； 上半球约定下极点方位 = 倾向。因此文献里写"极点落在反坡向"还是"落在坡向"，必须先看它用的是哪种约定—— 用本工具第①页切换一次半球，方位数字立刻互换，这个"读文献的坑"当场就讲明白了。

注：这些都是运动学（几何）判据，只回答"滑不滑得动、露不露得出"，不给出安全系数。工程结论仍需极限平衡或数值计算。 这正是赤平投影"只做初步判别"的原因，也是课堂上要反复强调的边界。
