## 二、怎么用（课堂建议流程）

### 1. 演示"平面投影图是怎么来的"
打开 `index.html` → 第①页 → 点 **▶ 播放"逐点投射"动画**，或按 ①②③④ 四个分步按钮：
1. 结构面过球心，与球面交出**大圆**；
2. 自**极射点**向大圆上的点连线；
3. 极射线与**赤平面**的交点即投影点；
4. 交点连成弧——这就是赤平投影图上的大圆。

拖动"倾向/倾角"滑块，左球右图同步变化，学生能直观看到"倾角变缓 → 大圆弧向基圆靠拢"。

### 2. 讲清"两种半球约定"
点第①页的 **上半球投影** 与 **下半球投影** 切换键，弧的凸向与极点的方位数字立刻互换。
这是读文献时最容易踩的坑：**同一套几何，只是投影视角相反**。工具第③页有对照表。

### 3. 吴氏网与施氏网的区别
切换 **等角（吴氏网）/ 等面积（施氏网）**：等角投影下大圆仍是圆弧，便于量角判稳；等面积投影下大圆变形，但面积守恒，适合做极点密度图。

### 4. 讲边坡稳定性判别
第②页输入坡面 cs、坡顶面 ns、两组结构面 J1/J2 与摩擦角 φ，自动给出三种破坏模式的判据校核。
预置了**平面滑动 / 楔形体滑动 / 倾倒破坏 / 整体稳定**四个算例，一键切换。

## 三、核心公式（可直接板书）

坐标系：x = 东，y = 北，z = 上，投影球半径 R。

**极射赤平投影**：设球面点 P(x, y, z)，自**上极点** N(0, 0, R) 发出的射线交赤平面于 Q，
令 Q_z = 0 得 u = R/(R − z)，于是

```
x' = R·x/(R − z)        y' = R·y/(R − z)
```

把 |P| = R 点写成"自竖直向下方向的夹角 θ"（θ = 90° − 伏角），得最常用的**投影半径公式**：

```
等角投影（吴氏网）：   r = R · tan(θ/2)
等面积投影（施氏网）： r = R · √2 · sin(θ/2)
```

设结构面倾角 β，则三个关键量的半径：

| 几何量 | 投影半径 | 方位 |
|---|---|---|
| 走向点（两个） | `R`（落在基圆上） | `α ± 90°` |
| 倾斜线（弧顶，最陡） | `R · tan(45° − β/2)` | `α` |
| 极点（法线） | `R · tan(β/2)` | `α + 180°`（下半球约定） |

**读数口诀**：弧端方位 = 走向；弧顶方位 = 倾向；**弧顶越靠近圆心 → 倾角越陡**
（β = 0° 时大圆与基圆重合；β = 90° 时退化为过圆心的直径）。
极点则相反：**基点越靠圆心 → 面越陡**；极点伏角 = 90° − 结构面倾角。

### 两种约定对照

| 约定 | 极射点 | 被投影半球 | 大圆凸向 | 极点方位 |
|---|---|---|---|---|
| **下半球投影** | 球的上极点 | 下半球 | 倾向 α | α + 180° |
| **上半球投影** | 球的下极点 | 上半球 | α + 180° | α |

两者的**半径数值完全相同，只是整体相差 180°**。国内部分工程地质教材习惯用上半球投影；
国际岩石力学（ISRM）、Hoek & Bray 边坡图解法及工程判稳常用的吴氏网多用下半球等角投影。

## 四、边坡稳定性的赤平投影判据（工具第②页自动校核）

**判别区以摩擦圆为分界线**（摩擦圆半径 `r/R = tan(45° − φ/2)`）：

- **圆内、坡向 ±20°（橙色）＝ 滑动出露区**，判读对象是**大圆弧顶**：
  弧顶落入即 `φ < 结构面倾角 < 坡角`；
- **圆外靠基圆、坡向 ±20°（粉色）＝ 倾倒区**，判读对象是**极点**：
  极点落入即结构面陡立且倾向坡内。

| 破坏模式 | 几何判据 |
|---|---|
| 平面滑动 | 结构面倾向与坡向之差 ≤ 20°；倾角 > φ；倾角 < 坡角（能在坡面剪出） |
| 楔形体滑动 | 两组结构面交棱线的倾伏向与坡向之差 ≤ 20°；倾伏角 > φ；倾伏角 < 坡角 |
| 倾倒破坏 | 结构面倾向与坡向**相反**（倾向坡内、走向与坡面近平行）；极点伏角 ≤ φ；坡角 ≥ 30° |

> ⚠️ **两个必须向学生强调的边界**
> 1. 这些都是**几何（运动学）判据**，只回答"滑不滑得动、露不露得出"，**不给安全系数**。
>    工程结论仍需极限平衡或数值计算。
> 2. 倾倒判据最容易讲错：倾倒要求结构面**倾向坡内**（倾向与坡向相反），
>    它的方位条件与平面滑动**正好相反**。伏角界限各文献取值略有差别：
>    规范类文献与香港《岩土工程手册》标准图取**极点伏角 ≤ φ**；
>    部分教材取简化的**≤ 30°**；Goodman & Bray 原式为 `90° − 结构面倾角 ≤ 坡角 − φ`。
>    工具把三者都列出来校核。

## 五、运行方法

### HTML（推荐，零依赖）
双击 `index.html`，或拖进 Chrome / Edge。支持 `index.html#v1`、`#v2`、`#v3` 锚点直达指定页面。
三维视图按住拖动可旋转、滚轮缩放。

### Python
```bash
pip install numpy matplotlib
python python/stereonet_demo.py            # 打开交互窗口
python python/stereonet_demo.py --export   # 只导出 figures/ 下的 4 张教学图
python python/stereonet_demo.py --export --also-show   # 两者都要
```

### MATLAB
把 `matlab/stereonet_demo.m` 放到当前目录，直接运行 `stereonet_demo`。
界面含倾向/倾角/投射进度三个滑块、半球约定与投影网单选框、播放动画与导出 PNG 按钮。

### 自检（改了代码之后建议跑一遍）
```bash
node verify_core_math.js    # 55 项公式断言
node verify_cases.js        # 4 个边坡算例回归
node verify_ui_smoke.js     # 界面渲染冒烟（穷举 89 种绘图组合）
```
