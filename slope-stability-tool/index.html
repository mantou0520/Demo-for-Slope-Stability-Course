三种方法的安全系数

整体圆弧法（仅 φ=0，饱和软黏土不排水强度 cu）
Fs = cu·L·R / (W·d)
抗滑力矩 ÷ 滑动力矩。L 为滑弧全长，d 为滑体重心到圆心的水平距离。φ≠0 时该式不成立，因为摩擦力沿弧面变化、无法整体求矩。
瑞典条分法（Fellenius，1927）
Fs = Σ[c·li + (Wicosαi − uili)tanφ] / ΣWisinαi
由「径向力平衡」得 Ni=Wicosαi，再对圆心取整体力矩平衡。忽略条间力，结果偏保守 10%–20%。
简化 Bishop（1955）
Fs = Σ{[c·bi + (Wi−uibi)tanφ]/mαi} / ΣWisinαi
mαi = cosαi + sinαi·tanφ / Fs
由「竖向力平衡」求 Ni，Fs 出现在等式两边，需迭代。与严格解相差通常 <5%。
简化 Janbu（补充，可用于非圆弧）
Fs = Σ[(c·bi+(Wi−uibi)tanφ)/nαi] / ΣWitanαi
nαi = cos²αi·(1 + tanαitanφ/Fs)
本工具按上式直接计算，未乘修正系数 f0（约 1.0），故数值略低于规范值。

为什么瑞典法算出来偏小（偏安全）？

忽略条间力后 Ni 只由 Wicosαi 提供，普遍小于真实值，摩擦力 tanφ 项被低估；而下滑力 ΣW sinα 不受影响，故 Fs 偏小。α 越大、坡越陡，误差越大。

为什么 φ=0 时三种方法结果相同？

φ=0 时 mα=cosα，Bishop 式化简为 Σc·b/cosα ÷ ΣW sinα = c·L ÷ ΣW sinα，与瑞典式完全一致，也等于 cuLR/(W·d)。工具里把 φ 拖到 0 就能看到三条结果重合——这是检查程序有没有写错的好办法。

土条数 n 取多少合适？

教材常取 b≈0.1R，n≈10。n 太小（<5）滑弧被折线化，误差可达 5% 以上；n 增大到 20 以后 Fs 基本不变。可在工具里把 n 从 6 拖到 30，看结果如何收敛。

最危险滑弧怎么找？

圆心 (x₀,y₀) 与半径 R 三个参数构成搜索空间，逐点试算取 Fs 最小。"搜索最危险滑弧"按钮做的是网格粗搜 + 局部细化，结果只作教学演示，工程上需按规范用更密的网格与多种滑面型式。

课堂使用建议（约 8 分钟讲完）

① 先建立"为什么条分"
把 φ 拖到 0，三种方法结果重合，说明 φ=0 时整体力矩平衡就够了；再把 φ 提到 15°，整体圆弧法失效——必须离散成条。
② 滑弧三个参数
拖动圆心、滚轮改半径，让学生看着 Fs 变。点"搜索最危险滑弧"，讲清"最危险"是搜出来的，不是猜出来的。
③ n 的影响
n 从 6 拖到 30，看 Fs 收敛到稳定值；顺带说明为什么教材取 n≈10（b≈0.1R）就够用。
④ 切到"未知数与方程"
用三个按钮当场划掉 E、X、h，把 5n−2 一步步降到 2n+1，学生自己就能算出黑板上的数字。
共同起点（三种方法都从这同一个受力图出发）
取第 i 个土条。作用力：自重 W、条底有效法向力 N′、孔隙水压力合力 U = u·l、条底剪力 T、 条间法向力 E、条间切向力 X。
可列 4 个方程：ΣFx = 0、ΣFy = 0、ΣM = 0、强度方程 T = (c′l + N′tanφ′)/F。
三种方法的区别只有两处，其余完全相同：
① 沿哪个方向投影求 N′ —— 瑞典法沿条底法向，Bishop／Janbu 沿竖直方向；
② 用哪个整体平衡方程收尾 —— 瑞典、Bishop 用对圆心取矩，Janbu 用水平力平衡。

瑞典条分法（Fellenius 1927）：先把条间力"关掉"，三步到底

假定 E = X = 0：n−1 个分界面上的 3 个未知量一次全部划掉，未知量从 5n−2 降到 2n+1。
1
沿条底法向投影求 N′
N = W·cosα
N′ = N − u·l = W·cosα − u·l
T 垂直于条底，在这个方向上分量为 0，所以式子里不出现 F。
2
强度方程
T = (c′l + N′·tanφ′) / F
把 ① 的 N′ 直接代入即可，无需求解方程。
3
对圆心取整体力矩平衡
ΣT·R = ΣW·R·sinα　→　ΣT = ΣW·sinα
F = Σ[c′l + (W·cosα − u·l)tanφ′] / ΣW·sinα
一次算完，不需要迭代。
关键一句：投影方向决定了要不要迭代。 沿条底法向投影时 T 的分量为零，N′ 里没有 F，可以单独解出； Bishop 改沿竖直方向投影，T 的竖直分量 T·sinα 进来了，F 就混进 N′，只能迭代。
代价是瑞典法把条间力全部丢掉：实际条间力一般会增大条底法向力，忽略后 N′ 偏小、摩擦力被低估， 所以 F 比严格解小 10%–20%（偏安全）。

简化 Bishop（1955）：走"整体力矩"这条路

1
沿竖直方向投影（不是条底法向）
N′·cosα + u·l·cosα + T·sinα = W
与瑞典法唯一的差别就在这里：改投影方向后 T 的分量 T·sinα 进来了。又因 l·cosα = b，孔压项 u·l·cosα = u·b。
2
强度方程（把 T 与 N′、F 绑起来）
T = (c′l + N′·tanφ′) / F
3
把 T 代回竖向平衡，解出 N′
N′·cosα + [(c′l + N′tanφ′)/F]·sinα = W − u·b
N′·[cosα + sinα·tanφ′/F] = W − u·b − c′l·sinα/F
N′ = (W − u·b − c′l·sinα/F) / mα
其中 mα = cosα + sinα·tanφ′/F，称为"修正系数"。
4
把 N′ 回代求 T
T = (c′l + N′tanφ′)/F = [c′b + (W − u·b)·tanφ′] / (F·mα)
关键一步（教材最常跳过的地方）：把 N′ 代入后分子通分，得
c′l·mα + (W−u·b)tanφ′ − c′l·sinα·tanφ′/F
把 mα 展开：c′l·mα − c′l·sinα·tanφ′/F = c′l·cosα = c′b。
那两项正好抵消，c′l 就这样变成了 c′b——分母上的 F 也随之提出去。
5
对圆心取整体力矩平衡（滑体两端 E 成对抵消）
ΣT·R = ΣW·R·sinα　→　ΣT = ΣW·sinα
F = Σ{ [c′b + (W − u·b)tanφ′] / mα } / ΣW·sinα
F 同时出现在 mα 里，无法直接解出，必须迭代。

简化 Janbu（1954）：走"水平力"这条路

1
同样假定 ΔX = 0
到这一步为止，与 Bishop 完全一样。分岔从下一步的收尾方程开始。
2
竖向平衡直接解出"总法向力" N
N·cosα + T·sinα = W　→　N = (W − T·sinα)/cosα
N 是总法向力，N = N′ + u·l。孔压已并入 N，式子里不再单独出现——这是与 Bishop 写法上的差别，实质相同。
3
对整个滑体列水平力平衡
Σ(Ei+1 − Ei) + Σ(T·cosα − N·sinα) = 0
滑体左右两端没有条间力，ΣΔE = 0，于是：
ΣT·cosα = ΣN·sinα
4
代入 N，用三角恒等式化简
ΣT·cosα = Σ(W − T·sinα)·tanα
ΣT·(cosα + sinα·tanα) = ΣW·tanα
ΣT / cosα = ΣW·tanα
关键一步：cosα + sinα·tanα = (cos²α + sin²α)/cosα = 1/cosα。
分母从 ΣW·sinα 变成 ΣW·tanα，就是这一行变出来的。
5
代入 T 的表达式（与 Bishop 的 ④ 相同）
T = [c′b + (W−u·b)tanφ′]/(F·mα)，而 mα = nα/cosα
F = Σ{ [c′b + (W−u·b)tanφ′] / nα } / ΣW·tanα
nα = cos²α·(1 + tanα·tanφ′/F)
同样要迭代；工程上最后再乘修正系数 f0（圆弧时 f0 ≈ 1）。

为什么瑞典法不用迭代，Bishop 要迭代？

只差在投影方向：沿条底法向投影时 T 分量为零，N′ 只与 W、u 有关；改沿竖直方向，T 的分量 T·sinα 进入方程，把 F 带了进来。

为什么 Bishop 只能算圆弧？

整体取矩时每个土条 T 的力臂恰好都是 R，可提到求和号外、两边约掉。非圆弧时力臂各异，这一步做不下去。

为什么 Bishop 与 Janbu 会差 10%？

力矩方程各条权重是 sinα，水平力方程是 tanα。α 大时 tanα 放大快，Janbu 对深滑弧偏低——这正是要乘 f0 的原因。
