## 一、未知数 2n+1 与方程 4n 是怎么来的

这是学生最容易懵的地方。关键在于：**先把一个"什么假定都不作"的条分模型数清楚，再一项项划掉。**

### 1. 未知量：5n−2

把滑体竖切成 n 个土条，条与条之间有 n−1 个分界面。

| 未知量 | 符号 | 个数 | 说明 |
|---|---|---|---|
| 条底法向力 | Nᵢ | n | 滑面对土条的法向反力 |
| 条底剪力 | Tᵢ | n | 滑面对土条的切向反力 |
| 条间法向力 | Eᵢ | n−1 | 相邻土条之间的水平推力 |
| 条间切向力 | Xᵢ | n−1 | 相邻土条之间的竖向摩擦 |
| 条间力作用点 | hᵢ | n−1 | 分界面上合力作用位置（取矩需要） |
| 安全系数 | Fₛ | 1 | 全局唯一，各条共用 |

合计：

```
n + n + 3(n−1) + 1 = 5n − 2
```

记忆法：**滑面 2n 个 + 每个分界面 3 个 + 全局 1 个**。

### 2. 方程：4n

每个土条可以列 4 个方程：

| 方程 | 个数 |
|---|---|
| 水平力平衡 ΣFₓ = 0 | n |
| 竖直力平衡 ΣF_y = 0 | n |
| 力矩平衡 ΣM = 0（对条底中点取矩） | n |
| 强度方程 Tᵢ = (c·lᵢ + Nᵢtanφ)/Fₛ | n |

合计 4n。注意第 4 类容易被忽略：正是这个方程把 Tᵢ 与 Nᵢ、Fₛ 绑在一起，否则 Tᵢ 无从确定。

### 3. 超静定次数 = (5n−2) − 4n = n − 2

n = 10 时：**48 个未知量、40 个方程，超静定 8 次**。
这就是为什么会有那么多种条分法——**每一种方法，本质上都是在补 n−2 个假定**。

### 4. 瑞典条分法：2n+1

Fellenius 假定"条间力对整体稳定影响不大"，直接把 n−1 个分界面上的 E、X、h 全部取零：

```
5n − 2 − 3(n−1) = 2n + 1      （n 个 N、n 个 T、1 个 Fₛ）
```

这正好解释了教材上的 2n+1。

### 5. 简化 Bishop：4n−1 ≈ 4n

Bishop 保留条间法向力 E，只假定**条间切向力 X = 0**（即条间合力水平）：

```
5n − 2 − (n−1) = 4n − 1
```

教材把 (n−1) 近似按 n 计，于是写作"4n 个未知数、4n 个方程"。
此时未知量与方程数目相当，故称"由超静定转化为静定"。

### 6. 一个必须讲透的点：方程数 ≠ 用到的方程数

| 方法 | 未知量 | 可列方程 | 实际用到的方程 | 放弃的方程 |
|---|---|---|---|---|
| 通用模型 | 5n−2 | 4n | 4n（但彼此不独立） | — |
| 瑞典法 | 2n+1 | 4n | **2n+1**（n 条径向平衡 + n 个强度 + 1 个整体力矩） | 2n−1 |
| 简化 Bishop | 4n−1 | 4n | **2n+1**（n 条竖向平衡 + n 个强度 + 1 个整体力矩） | 2n−1 |

- 瑞典法看起来"方程比未知数多"，其实它**只用了其中 2n+1 个**，剩下的 2n−1 个（各条切向平衡与力矩平衡）根本不满足——这就是"瑞典法不满足全部平衡条件"的确切含义，也是它偏保守（Fₛ 偏小 10%–20%）的根源。
- Bishop 也是用 2n+1 个方程，但换成了**竖向力平衡**（比"径向平衡"更接近真实受力），法向力 N 由竖向平衡 + 强度方程联立解出，Fₛ 出现在等式两边，所以要迭代。
- Bishop 形式上剩下的 Eᵢ 不出现在竖向平衡里（E 是水平的），因此它们虽然未知却不影响 Fₛ——这是"4n 个未知数、4n 个方程"能解的另一层原因。

### 7. 数量对照（可直接板书）

| n | 通用 5n−2 | 超静定 n−2 | 瑞典 2n+1 | Bishop 4n−1 | 方程 4n |
|---|---|---|---|---|---|
| 4 | 18 | 2 | 9 | 15 | 16 |
| 8 | 38 | 6 | 17 | 31 | 32 |
| 10 | 48 | 8 | 21 | 39 | 40 |
| 20 | 98 | 18 | 41 | 79 | 80 |

## 二、三种方法的安全系数

**整体圆弧法**（仅 φ = 0，饱和软黏土不排水强度 c_u）

```
F_s = c_u · L · R / (W · d)
```

L 为滑弧全长，d 为滑体重心到圆心的水平距离。φ ≠ 0 时该式不成立——摩擦力沿弧面随正应力变化，无法整体求矩。

**瑞典条分法**（Fellenius, 1927）

```
F_s = Σ[c·lᵢ + (Wᵢcosαᵢ − uᵢlᵢ)tanφ] / ΣWᵢsinαᵢ
```

由径向力平衡得 Nᵢ = Wᵢcosαᵢ，再对圆心取整体力矩平衡。

**简化 Bishop**（1955）

```
F_s = Σ{[c·bᵢ + (Wᵢ − uᵢbᵢ)tanφ] / m_αᵢ} / ΣWᵢsinαᵢ
m_αᵢ = cosαᵢ + sinαᵢ·tanφ / F_s          （需迭代）
```

**简化 Janbu**（补充，可用于非圆弧）

```
F_s = Σ[(c·bᵢ + (Wᵢ − uᵢbᵢ)tanφ)/n_αᵢ] / ΣWᵢtanαᵢ
n_αᵢ = cos²αᵢ (1 + tanαᵢ·tanφ/F_s)
```

本工具未乘修正系数 f₀（约 1.0），数值略低于规范值。

## 四、正确性怎么保证

```
node verify_core_math.js    # 39 项断言
node verify_ui_smoke.js     # 97 次回调，无异常
```

最有力的一条自检：**φ = 0 时三种方法必须给出同一个 Fₛ**。因为 m_α = cosα，Bishop 式退化为 Σc·b/cosα ÷ ΣW sinα = c·L ÷ ΣW sinα，与瑞典式、整体圆弧法完全一致。实测三者相等至小数点后 8 位（0.66615632）。

其余断言包括：Σl·cosα 等于滑弧水平投影、sinα = (x−x₀)/R、ΣW·sinα 与 ΣW(x−x₀)/R 一致、Fₛ 随 φ 单调递增、n 增大收敛、孔压使 Fₛ 下降、5n−2 与 2n+1 / 4n−1 的代数恒等式，两条推导链的**平衡残差**（Bishop 力矩残差 4.9e-10 %，Janbu 水平力残差 6.1e-9 %），以及下面这个教材算例。

### 教材算例回归（第 [13] 组断言）

H=8 m、坡角 55°、γ=20 kN/m³、φ=12°、c=20 kPa，圆心 (−0.4, 8.0)、R=8.01 m、n=10：

| 方法 | 本工具 | 教材 |
|---|---|---|
| 瑞典条分法 | **1.043** | 1.045 |
| 简化 Bishop | 1.074 | — |

差 0.2%，属分条位置与教材手工分条不完全一致所致。

**顺带修掉的一个 bug**：早期版本只用"整条弧都在土内"来判断无效滑弧，漏掉了"圆弧一端（圆顶）埋在土里、滑面没有出口"这种情况。这类圆会被当成有效滑弧，`l = b/cosα` 在弧端接近竖直时失真，给出虚假的低值（本次算例中曾低到 0.95）。现已改为**两端都必须真正穿出地面**，并把这个圆加入断言。

### 关于分条数 n

瑞典法对 n 比 Bishop 敏感：同一滑弧，n=8 与 n=30 的结果可差 3%–5%（n 小则偏低）。与教材算例对照时，建议 n 取 10–15，并直接输入教材给出的圆心与半径。

## 五、三种方法的推导要点

**共同起点**：土条受力 W、N′、U=ul、T、E、X；四个方程（ΣFₓ、ΣF_y、ΣM、强度方程）。

三种方法的差别只有两处：
① **沿哪个方向投影**求 N′ —— 瑞典法沿**条底法向**，Bishop／Janbu 沿**竖直方向**；
② **用哪个整体平衡方程**收尾 —— 瑞典、Bishop 用**对圆心取矩**，Janbu 用**水平力平衡**。

### 瑞典条分法（Fellenius 1927）：先把条间力关掉

假定 **E = X = 0**（未知量从 5n−2 降到 2n+1）。

```
① 沿条底法向投影   N = W·cosα  →  N′ = N − u·l = W·cosα − u·l
② 强度方程         T = (c′l + N′tanφ′)/F
③ 对圆心取矩       ΣT·R = ΣW·R·sinα  →  ΣT = ΣW·sinα
                  F = Σ[c′l + (W·cosα − u·l)tanφ′] / ΣW·sinα
```

**关键一句**：沿条底法向投影时 T 的方向与该方向垂直、分量为 0，所以 N′ 里**不含 F**，可以单独解出，一次算完、不需迭代。代价是丢掉全部条间力，N′ 偏小、摩擦力被低估，F 比严格解小 10%–20%（偏安全）。

### 简化 Bishop（假定 ΔX = 0，收尾：对圆心取矩）

```
① 竖直方向投影  N′cosα + u·l·cosα + T·sinα = W
② 强度方程      T = (c′l + N′tanφ′)/F
③ 解 N′         N′ = (W − u·b − c′l·sinα/F) / m_α
④ 回代求 T      T = [c′b + (W−u·b)tanφ′] / (F·m_α)
⑤ 整体取矩      F = Σ{[c′b + (W−u·b)tanφ′]/m_α} / ΣW·sinα
```

`m_α = cosα + sinα·tanφ′/F`

改沿竖直方向后 T 的分量 T·sinα 进来了，F 就混进 N′——这正是 Bishop 必须迭代、而瑞典法不必的原因。

**第 ④ 步是教材最常跳过的一步**：把 N′ 代入后分子通分，得

```
c′l·m_α + (W−ub)tanφ′ − c′l·sinα·tanφ′/F
```

其中 `c′l·m_α − c′l·sinα·tanφ′/F = c′l·cosα = c′b`（因为 l·cosα = b）。
这两项恰好抵消，**c′l 就变成了 c′b**，分母的 F 也随之提出。

### 简化 Janbu（收尾：整体水平力平衡）

```
① 假定        ΔX = 0
② 竖向平衡    N·cosα + T·sinα = W  →  N = (W − T·sinα)/cosα
③ 水平力平衡  Σ(Eᵢ₊₁ − Eᵢ) + Σ(T·cosα − N·sinα) = 0，两端 E = 0
              → ΣT·cosα = ΣN·sinα
④ 代入 N      ΣT(cosα + sinα·tanα) = ΣW·tanα
              cosα + sinα·tanα = 1/cosα  →  ΣT/cosα = ΣW·tanα
⑤ 代入 T      F = Σ{[c′b + (W−u·b)tanφ′]/n_α} / ΣW·tanα
```

`n_α = cos²α·(1 + tanα·tanφ′/F) = m_α·cosα`

**第 ④ 步的关键恒等式**：`cosα + sinα·tanα = (cos²α + sin²α)/cosα = 1/cosα`。
分母由 ΣW·sinα 变成 ΣW·tanα，就是这一行变出来的。

### 三条"为什么"

| 问题 | 答案 |
|---|---|
| 为什么瑞典法不用迭代，Bishop 要迭代？ | 只差投影方向：沿条底法向时 T 分量为 0，N′ 只与 W、u 有关；沿竖直方向时 T·sinα 进入方程，把 F 带了进来 |
| Bishop 为什么只能算圆弧？ | 整体取矩时每个土条 T 的力臂都是 R，可提到求和号外约掉；非圆弧力臂各异，做不下去 |
| 同样 ΔX=0，Bishop 与 Janbu 为何差 10%？ | 力矩方程权重是 sinα，水平力方程是 tanα；α 大时 tanα 放大快，Janbu 对深滑弧偏低 → 乘 f₀ 修正 |

### 残差验证

把算出的 F 代回检查平衡：

- Bishop：`ΣT − ΣW·sinα` 残差 **4.9e-10 %**
- Janbu：`Σ(T·cosα − N·sinα)` 残差 **6.1e-9 %**
- 瑞典：按文档的 `N′ = Wcosα − ul` 重构，与实现的 F 定义式完全一致

Bishop 与 Janbu 的残差趋零说明：**这两条公式是"ΔX=0 + 竖向平衡 + 各自收尾方程"的严格解**，不是经验拟合。

## 六、课堂流程（约 8 分钟）

1. **φ 拖到 0** → 三法重合，说明 φ=0 时整体力矩平衡就够；**φ 提到 15°** → 整体圆弧法失效，必须离散成条。
2. **拖动圆心、滚轮改半径** → 看 Fₛ 怎么变；点"搜索最危险滑弧"，讲清"最危险"是搜出来的。
3. **n 从 6 拖到 30** → 看 Fₛ 收敛；说明教材取 b≈0.1R、n≈10 的由来。
4. **切到第 ② 页**，依次点三个按钮 → 当场划掉 E、X、h，5n−2 一步步降到 2n+1，学生自己就能算出黑板上的数字。
