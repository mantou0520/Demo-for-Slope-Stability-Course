# 黏性土边坡稳定性：平面应变弹塑性有限元 + 强度折减法（MATLAB）

单文件脚本 `slope_fem.m`，只用 MATLAB 基础功能，不依赖任何工具箱。
给定坡高、坡角、重度、c、φ，网格自动生成，**先算地应力、再折减强度**，
用二分法求安全系数，并输出网格图、位移、应力、von Mises、塑性应变等整套云图。

```
slope-fem-matlab/
├── slope_fem.m      主程序（网格、Q4 单元、Mohr-Coulomb 返回映射、两阶段求解、强度折减、绘图）
├── figures/         默认算例输出（11 张图）
└── README.md
```

## 一、快速开始

```matlab
% 默认算例：H=10 m，坡角 45°，γ=18，c=20 kPa，φ=15°
slope_fem

% 改几何与参数
slope_fem('H',12,'beta',50,'c',25,'phi',18,'gamma',19)

% 只看结果、不出图
Fs = slope_fem('beta',60,'export',false);

% 扫不同坡角（输出 Fs 表 + Fs–β 曲线）
slope_fem('sweep',true,'sweepBeta',[30 40 50 60 70])

% 换网格密度（默认 48×24，节点 1225、单元 1152）
slope_fem('nx',60,'ny',30)

% 指定绘图时用的折减系数（默认自动取 0.99Fs，不收敛则回退）
slope_fem('Fplot',1.20)

% 把解存成 mat，便于事后改图
slope_fem('save','res.mat')
```

命令行无界面运行（验证/批量出图用）：

```bat
matlab -batch "cd('D:\...\slope-fem-matlab'); slope_fem"
```

## 三、算法

**1. 网格**：贴坡面的结构化四边形网格。每一竖列的节点从坡底等分到坡面，
所以顶行节点严格落在坡面线上，坡面不会被锯齿化。单元为逆时针 Q4。

**2. 单元与积分**：四节点等参元，2×2 高斯积分，平面应变 D 矩阵。

**3. 本构**：Mohr-Coulomb 理想弹塑性，非关联流动（ψ 默认 0）。
屈服函数写成平面应变的等价形式

```
f = t + p·sinφ − c·cosφ ,   p = (σx+σy)/2 ,  t = √(((σx−σy)/2)² + τxy²)
```

> **注意符号**：本程序压应力为**负**，所以是 `+ p·sinφ`。
> 若写成 `− p·sinφ`，静水压缩也会被判为屈服，整个坡体会出现虚假塑性。

返回映射：从弹性预测点出发，沿塑性势梯度方向校正，3 次内层迭代即可满足 f≈0。
切线模量用连续切线 `D_ep = D − (D·g)(aᵀD)/(aᵀD·g)`。

**4. 两阶段求解（关键）**

```
阶段 I  自重固结：真实强度下把重力分 nsteps 级加到全载
        → 得到与重力平衡的地应力场 σ₀，记录沉降，然后 u := 0、ep := 0
阶段 II 强度折减：把 σ 退回降低后的屈服面（每子步一次），再迭代平衡
        c → c/F，tanφ → tanφ/F，子步从 F=1 线性降到目标 F
        u、ep 均从零计 —— 云图反映折减引起的附加变形，即破坏机制
```

**为什么一定要分两阶段**：如果直接从零应力加自重，位移里混着整个土体的
压缩沉降（u ∝ γH²/E，地面处最大），云图会显示"坡顶位移最大"，
与滑动机制无关；而 σ 从零开始、又在折减后的强度下加载，会让深部土体
从一开始就大范围屈服，产生虚假塑性区。分两阶段后这两个问题同时消失。

**5. 强度折减**：二分搜索使边坡「刚好还能收敛」的最大 F：

```
F_lo = 0.6（必收敛）, F_hi = 3.0（必失稳），二分 8 次 → 分辨率约 0.008
```

失稳判据有两条：**Newton 迭代在 maxit 内不收敛**，或 **max|u| > 0.02H**。

### 与极限平衡法对比（H=10 m，γ=18，c=20 kPa，φ=15°）

| 坡角 β | 简化 Bishop | **本程序 (FEM-SRM)** | 偏差 |
|---|---|---|---|
| 30° | 1.512 | **1.500** | −0.8% |
| 45° | 1.177 | **1.256** | +6.7% |
| 60° | 0.968 | **1.012** | +4.5% |

（Bishop 值由 `../slope-stability-tool/` 搜索最危险滑弧得到；FEM 取 nx=44/48。）

45° 时瑞典条分法为 1.149。三个坡角的偏差都在 7% 以内，随坡角单调、量级正确，
说明网格、本构、返回映射与两阶段流程都是自洽的。

### 网格敏感性（H=10，β=45°，nF=6）

| 网格 | nx=24 | nx=36 | nx=48 |
|---|---|---|---|
| Fs | 1.350 | 1.275 | 1.237 |

Fs 随网格加密**下降**并趋于 ~1.2。这是经典弹塑性（无正则化、无特征长度）的固有
网格依赖性——剪切带越薄、越集中，表观强度越低。教学与对比时建议固定 `nx=48, ny=24`
并在报告中注明网格。若要做定量研究，应引入正则化（非局部、梯度塑性或黏性）。

### 弹性模量的影响（nx=32，nF=6）

| E (MPa) | Fs | max\|u\| |
|---|---|---|
| 20 | 1.275 | 10.25 mm |
| 100 | 1.275 | 2.05 mm |

**Fs 完全不变，位移严格按 1/E 缩小（正好 5.00 倍）。** 云图形状也不变。
即：调 E 只能改变"变形看起来有多大"，不能改变"会不会滑动"，
更不能修正初始地应力或应力集中的问题。

### 静止侧压力系数 K₀ 的影响（nx=48，nF=6）

| ν | K₀ = ν/(1−ν) | Fs |
|---|---|---|
| 0.30 | 0.43 | 1.200 |
| 0.426（Jaky，默认） | 0.74 | 1.237 |

差约 3%，属于非关联流动 + 初始应力场的正常敏感性。默认取 Jaky K₀ 的理由见下节。

## 六、常见问题

**Q：为什么位移最大处不在坡顶，而在坡面上？**

因为云图画的是**相对自重固结状态的增量位移**。若直接从零应力加载，
每个节点的位移是它下方土柱的累计压缩量，越靠地表越大——那是沉降，不是滑动。
本程序在阶段 I 结束后把 u 清零，剩下的才是强度折减引起的破坏变形：
坡面外鼓、坡顶下沉，最大值自然落在坡面中上部。

**Q：为什么塑性剪应变集中在坡趾？这不该是三向等压吗？**

深部土体**不是**三向等压。σv = γz，σh = K₀σv 且 K₀ < 1，
偏应力 t = (σv − σh)/2 = (1−K₀)γz/2，约为竖向应力的 13%~30%，并不小。
是否屈服要把 t 和 c·cosφ + σn·tanφ 相比：
K₀ = 0.43、φ = 15°、c = 20 kPa 时，地面以下约 10 m 的弹性 K₀ 应力状态就已越过屈服面。
而坡趾是几何转折点，应力集中 + 最小围压，是塑性最先出现、剪应变最大的地方——
这正是滑弧的**剪出口**。

**Q：那 08 图里坡顶后面那片蓝色/黄色区域是什么？**

那是坡顶后方的**主动区**：坡面被推出后，坡顶后方土体向下、向坡面方向让位，
在折减到 0.99Fs 时已大范围进入塑性。它与坡趾的塑性区连起来，构成滑体边界。
想让它更"薄"、更像一条圆弧，需要加密网格或引入应变软化/正则化。

**Q：把 E 调大能不能解决上面这些问题？**

不能。E 只缩放位移量级（u ∝ 1/E），Fs 与变形模式完全不变（见第五节实测）。
真正要改的是**初始应力场**（是否可分、K₀ 是否合理）和**绘图口径**（是否扣除沉降）。

**Q：Fs 算出来是 NaN？**

表示 Fmin=0.6 时仍不收敛，即边坡在该强度下已经失稳，真实 Fs < 0.6。
把 `Fmin` 调小（如 0.3）再试。

**Q：能不能算多层土？**

当前是均质单层。多层需要按单元赋材料（改 `make_material` 为按 y 坐标分段，
`assemble` 里按单元取对应材料），改动量不大。

## 七、与网页版工具的分工

- `../slope-stability-tool/`（网页）：**极限平衡法**（整体圆弧、瑞典、Bishop、Janbu），
  秒出结果，适合课上快速对比各种假定。
- 本脚本：**有限元强度折减法**，能给应力场、位移场、塑性区，适合讲"变形与破坏机制"。

两者在同一算例上相差 7% 以内，可以互相印证；差异本身也是个好话题——
极限平衡法假定滑面上同时达到极限，有限元则允许塑性区逐步扩展。
